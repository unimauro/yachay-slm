Modelo de lenguaje propio · desde cero · hecho en Perú

Yachay SLM

yachay — «conocimiento, aprender» (quechua)

Entrena en una laptop. Corre en un juguete. Un modelo propio, abierto, que cabe donde ningún otro entra.

2 tracks corre sin GPU MLX · NumPy · Rust Raspberry Pi · IoT RAG local · privado licencia MIT
Por qué

Soberanía, privacidad y costo — no ranking

No busca competir con GPT. Busca un cerebro pequeño que puedas poseer, auditar y correr on-device: en infraestructura chica, hardware reciclado y juguetes educativos. Un modelo diminuto no lo sabe todo — pero puede ser tuyo, y estar donde los grandes no llegan.

Cómo

Dos tracks, dos objetivos

«General + diminuto + desde cero» no coexisten: es física del modelo. Así que el proyecto avanza en dos caminos complementarios.

Track A · soberano

Yachay-Nano

Un modelo desde cero, propio y diminuto (~1–7M parámetros). Habla el idioma de un nicho acotado y cabe en el hardware más chico.

  • nanoGPT entrenado en MLX
  • Inferencia en NumPy puro y en Rust nativo
  • Para microcontroladores y juguetes de propósito único
Track B · útil ya

Yachay-General

Afinar (LoRA) un modelo chico ya preentrenado (Qwen2.5-0.5B). Multifuncional de verdad, corre en Raspberry Pi o PC vieja.

  • Fine-tuning en tu Mac con mlx-lm
  • Export a GGUF 4-bit (~350 MB) para llama.cpp
  • Sigue siendo abierto y tuyo — pero no «desde cero»

La idea grande

De un modelo propio a una red de la comunidad

El sueño no es un modelo — es que las propias máquinas, en red, contribuyan con respuestas. Aterrizado en pasos, del más barato al más ambicioso.

  1. Datos comunitariosAportar y curar pares de calidad. Barato, empieza ya.
  2. Registro de modelosPublicar cada versión para que cualquiera la baje y corra.
  3. Inferencia distribuidaNodos de la comunidad respondiendo consultas.
  4. Entrenamiento descentralizado«Napster para modelos»: CPU/GPU ociosa de voluntarios entrena, coordinado. Investigación pura, horizonte lejano.
Honestidad de alcance

Para SLMs diminutos, descentralizar el entrenamiento aporta poco: la gracia es que corren enteros en una máquina chica. El valor que sí llega pronto es la fila 1–2: datos de la comunidad → reentrenar barato → redistribuir. Eso ya es contribuir de verdad.

Súmate

Cómo contribuir

Es abierto (MIT). Clona, córrelo en tu máquina, propón datos o mejoras. Hay sitio para todos: quien entrena, quien aporta datos, quien lo lleva a un dispositivo.

Pruébalo en 2 minutos

Sin GPU, sin API key. Trae un modelo demo listo.

# cualquier equipo, sin MLX
git clone https://github.com/unimauro/yachay-slm
cd yachay-slm
pip install -r requirements-portable.txt
python -m src.portable.run --chat
